Pain Points

你还在这样下载吗？

每个国内开发者都经历过的痛点，SuperGit 一次性解决。

下载龟速

Release 源码包动辄几十 MB，从 GitHub 直接下载速度不到 50 KB/s，一个 ZIP 等十几分钟是常态。

图片裂开

Raw 原始文件和 GitHub Pages 资源在国内频繁加载失败，README 里的图片全是裂图，文档无法阅读。

连接超时

clone 大仓库时 SSH/HTTPS 频繁超时断连，CI/CD 流水线因拉取依赖失败而阻塞。

Features

全方位加速体验

不只是替换链接，SuperGit 提供完整的镜像加速解决方案。

自动注入下载按钮

无需手动复制链接到镜像站，SuperGit 会在 GitHub 页面自动注入绿色的「镜像下载」按钮。点击后弹出镜像节点列表，一键选择最优节点即可下载。智能识别 GitHub SPA 路由切换，页面跳转后自动重新注入。

智能节点管理

右下角浮动面板管理镜像节点，支持手动勾选、全选、Top10 快捷设置。每个节点实时显示延迟，支持单节点测速。节点数据自动缓存 10 分钟，减少 API 请求。

右键菜单加速

在任意 GitHub 下载链接上右键，直接选择镜像节点下载，无需额外操作。右键菜单节点与面板管理同步，勾选即生效。

按钮显示可控

节点管理面板内置「下载按钮」配置 Tab，支持按场景独立开关：Release ZIP、附件、Raw 文件、Clone 弹框等，可自定义哪些位置注入按钮。

动态内容适配

GitHub 大量内容通过交互动态渲染（下拉菜单、折叠面板、懒加载），SuperGit 通过 MutationObserver 持续监听 DOM 变化，确保动态加载的下载链接也能及时注入。

GitHub Hosts

修改 Hosts 解决访问问题

GitHub 在国内偶尔无法直接访问，通过修改系统 Hosts 文件指向可用 IP 即可恢复。以下内容每日自动更新。

此功能与 SuperGit 浏览器插件无关，是解决 GitHub 本身无法访问的问题。如果你能正常打开 GitHub 页面，无需此操作。

  • 将复制的 Hosts 内容粘贴到文件末尾

FAQ

常见问题

SuperGit 安全吗？会上传我的数据吗？

SuperGit 完全本地运行，不会收集、上传任何用户数据。插件仅请求镜像节点列表 API（api.akams.cn/github），该 API 为公开接口。所有下载操作通过浏览器原生下载功能完成。

镜像节点的延迟数据准确吗？

节点延迟由服务端定期测速后提供，反映的是节点服务器到 GitHub 的延迟。实际下载速度还受你本地网络到镜像节点的链路影响，建议使用面板中的「测速」按钮测试到节点的实际延迟。

为什么有些页面看不到下载按钮？

请确认：1) 节点管理面板中对应场景的开关是否开启；2) 尝试刷新页面；3) 如果是动态加载内容（如展开的折叠面板），稍等片刻按钮会自动注入。如仍有问题，可在面板中提交反馈。

支持 Firefox 和 Safari 吗？

SuperGit 基于 Chrome Extensions Manifest V3 构建，完美支持 Chrome、Edge、Brave、Arc 等 Chromium 内核浏览器。Firefox 可通过临时加载方式使用（需手动适配），Safari 暂不支持。

节点多久更新一次？

插件启动时优先从本地缓存加载节点（秒开），每 10 分钟自动在后台静默刷新节点列表。你也可以随时在节点管理面板点击「刷新节点」手动更新。
